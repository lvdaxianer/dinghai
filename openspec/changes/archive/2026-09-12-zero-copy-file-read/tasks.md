## 3. Provider 缓存生命周期隔离

- [x] 3.1 Local 一律不装配二级缓存和清理器（含显式 `cache.enabled=true`，启动拒绝并提示配置已移除），校验缓存根目录冲突。

## 4. 资源边界与兼容性
